# Source References

Các tài liệu dưới đây được sử dụng làm reference khi consolidate Git workflow trong pack này:

- Quy trình tạo nhánh (Branching Strategy).xlsx
- Quy trình commit chuẩn (Commit Convention).xlsx
- Quy trình Pull Request và Merge.xlsx
- Tài liệu tuân thủ GIT.xlsx

Pack này **không copy nguyên trạng** các file trên. Nội dung đã được chuẩn hóa và gom nhóm để member mới có một nơi đọc thống nhất.

Khi source Git process thay đổi, cần review lại `git-flow.md` và `git-rules.md` tương ứng.
